# Guía de contribución

## Antes de comenzar
- Clonar el repositorio y actualizar la rama principal.
- Revisar el README y la documentación relacionada con la tarea.
- Comprobar que el entorno local esté configurado.

## Cambios
- Realizar cambios pequeños y relacionados con una tarea.
- Mantener la organización actual del proyecto.
- Usar consultas SQL parametrizadas.
- No incluir credenciales, datos reales ni archivos generados.
- Actualizar la documentación cuando cambie el comportamiento o el modelo de datos.

## Commits
Usar mensajes claros, por ejemplo:
- docs: actualizar instrucciones de instalación
- feat: agregar registro de clientes
- fix: validar disponibilidad de citas
- test: documentar pruebas de agenda

## Revisión
1. Compilar la solución.
2. Ejecutar las pruebas relacionadas.
3. Revisar los archivos modificados.
4. Confirmar que no se incluyan secretos ni archivos temporales.
