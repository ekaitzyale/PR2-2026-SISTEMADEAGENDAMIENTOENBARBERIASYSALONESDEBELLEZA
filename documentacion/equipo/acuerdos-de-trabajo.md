# Acuerdos de trabajo del equipo

1. Mantener el repositorio como fuente común del proyecto.
2. Antes de modificar archivos compartidos, revisar los cambios recientes.
3. Realizar commits pequeños y con mensajes descriptivos.
4. No subir carpetas generadas como .vs, bin y obj.
5. No publicar contraseñas, tokens, cadenas de conexión privadas ni datos reales de clientes.
6. Mantener requisitos, diagramas y README sincronizados con el código real.
7. Registrar tareas pendientes, bloqueos y responsables en GitHub Issues o en el mecanismo acordado.
8. Probar cada función antes de marcarla como terminada.
9. Revisar los cambios antes de integrarlos a main.
10. Comunicar al equipo los cambios de alcance y decisiones técnicas.
