## Criterio de actualización

Cada tema tiene un documento principal. La documentación debe distinguir entre propuesta, implementación visible en el repositorio y pruebas ejecutadas. Mantener enlaces actualizados y no declarar como realizado algo que no tenga evidencia verificable.
