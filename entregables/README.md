# Entregables académicos

Guardar aquí únicamente las versiones finales solicitadas para la entrega académica.

Posibles entregables, según la consigna y las indicaciones del docente:
- Informe final en PDF.
- Manual de usuario o manual técnico, si corresponde.
- Presentación final exportada, si se solicita una copia.
- Otros archivos expresamente solicitados.

Los borradores y documentos de trabajo permanecen en sus carpetas de documentación. Antes de entregar, comprobar que los archivos correspondan a la versión final revisada y que los enlaces funcionen.
