# Sistema

Esta carpeta contiene los archivos necesarios para construir, configurar y ejecutar la aplicación.

- `codigo/`: solución de Visual Studio (`.sln`), proyectos (`.csproj`) y código fuente.
- `base-datos/`: scripts SQL para crear la base de datos y, si corresponde, insertar datos de prueba.
- `recursos/`: imágenes, iconos y recursos utilizados por la interfaz.

La solución de Visual Studio y el script SQL todavía deben ser incorporados por el equipo. No guardar aquí carpetas generadas como `.vs`, `bin` u `obj`.
