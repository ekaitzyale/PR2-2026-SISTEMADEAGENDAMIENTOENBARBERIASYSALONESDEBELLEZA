# Seguridad

## Alcance

Este es un proyecto académico en desarrollo. No se ofrece un servicio de soporte de seguridad permanente ni se garantiza que la aplicación esté preparada para producción.

## Reportar un problema

No publiques vulnerabilidades, credenciales, cadenas de conexión, datos personales ni pasos que expongan información sensible en una incidencia pública.

Para informar un problema, contacta directamente a los mantenedores del repositorio por un canal privado acordado por el equipo y proporciona:
- Descripción breve del problema.
- Pasos para reproducirlo sin datos reales.
- Impacto observado.
- Versión o commit afectado.

El equipo revisará el reporte y coordinará una corrección antes de divulgar detalles.

## Buenas prácticas para el desarrollo

- Usar datos ficticios durante pruebas.
- No versionar contraseñas ni secretos.
- Mantener la cadena de conexión local y adaptarla por entorno.
- Usar consultas SQL parametrizadas.
- Validar los datos antes de guardarlos.
- No incluir información personal real en capturas o incidencias.
