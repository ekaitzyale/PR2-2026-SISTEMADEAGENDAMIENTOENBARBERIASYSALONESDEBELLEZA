# Política de seguridad

## Reporte de problemas
Si se identifica una vulnerabilidad o exposición de información sensible, comunicarla directamente al equipo responsable del repositorio antes de divulgarla públicamente.

## Protección de información
- No subir contraseñas, tokens, claves ni cadenas de conexión con credenciales.
- Mantener la configuración local fuera del control de versiones cuando contenga datos privados.
- Utilizar datos ficticios en pruebas y evidencias.
- No publicar información personal real de clientes.
- Utilizar consultas parametrizadas para evitar inyección SQL.

## Alcance
Este proyecto es académico y está en desarrollo. No debe utilizarse para almacenar información real de clientes sin revisar previamente sus medidas de seguridad y privacidad.
