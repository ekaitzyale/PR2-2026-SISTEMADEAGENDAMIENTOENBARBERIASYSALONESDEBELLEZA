# PR2-2026 — SISTEMA DE AGENDAMIENTO Y GESTIÓN PARA BARBERÍAS Y SALONES DE BELLEZA

> Equipo: **Virus** | Universidad Privada "Franz Tamayo" | Cochabamba, Bolivia

---

## 🎯 ¿Qué problema resolvemos?
Las barberías y salones de belleza en Cochabamba gestionan citas en cuadernos físicos y mensajes de WhatsApp. Esto provoca:
- ❌ Superposición y doble reserva de citas
- ❌ Pérdida de tiempo del personal atendiendo consultas
- ❌ Sin historial confiable de clientes ni métricas del negocio
- ❌ Demoras e incertidumbre para los clientes

## ✨ Propósito
Desarrollar una aplicación de escritorio que **automatice y centralice** el agendamiento de citas, eliminando errores humanos, optimizando tiempos y mejorando la experiencia de clientes y profesionales.

## 👥 Usuarios del sistema
| Perfil | Qué obtienen |
|---|---|
| **Propietarios/Administradores** | Control global, métricas en tiempo real, registros organizados |
| **Profesionales (barberos/estilistas)** | Horarios sin empalmes, jornada clara |
| **Clientes** | Reservas seguras, confirmación inmediata |

## 📋 Objetivos del proyecto
- ✅ Base de datos relacional en **SQL Server** normalizada
- ✅ Aplicación de escritorio en **C# + Windows Forms** con operaciones CRUD completas
- ✅ Algoritmo de validación que **impide citas solapadas** automáticamente
- ✅ Panel de control con métricas: citas programadas, atendidas, canceladas
- ✅ Módulo de historial, reportes y facturación

## 🛠️ Tecnologías
- **Lenguaje:** C# (.NET Framework)
- **Interfaz:** Windows Forms
- **Base de datos:** SQL Server
- **Conexión:** ADO.NET
- **Entorno:** Visual Studio
- **Control de versiones:** GitHub
